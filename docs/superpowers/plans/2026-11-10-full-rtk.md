# RTK historical output filter port

Upstream: RTK 0.49.0, `653efb6ed02bd287d686c50e830dd1009356904f`.

## Scope and constraints

Port the Apache-2.0 CLI's historical-text filtering: the complete pipe registry,
built-in declarative rules, and native text filters usable without running commands.
Keep unknown formats intact. Execution, telemetry, hooks, recall, external reports,
filesystem inspection, and the separately licensed engine/proxy are outside this
history-only integration. Inventory these boundaries explicitly; registry entries
must point to working implementations, never placeholder filters.

Keep the existing age/activity/history and SQLite coordination safeguards. Never
run cleanup, cleanup previews, native deletion tests, or `npm test`. Use synthetic
fixtures, `npm run test:read-only`, typecheck, and build. No commits or branch
changes are authorized. The current branch predates history slimming, so its
runtime/test prerequisites were restored as source changes from local main at
`2049251414db798e6cf0a0796219a3d558458f53`, retaining age/activity checks and
SQLite coordination. No merge, branch switch or worktree creation was performed.

   Export `matchRtkRule(command): string | undefined`, `filterRtkRule(name,input)`.
   Retain original rules/tests and a reproducible conversion script. Test every

3. Inventory native command filters outside pipe; port pure historical-text
   transforms in `src/vendor/rtk-native.ts`, with `nativeFilters` and
   `matchNativeFilter(argv: string[]): string | undefined`. Add source mapping and
   synthetic tests in `test/rtk-native.test.ts`.
4. Integrate the registry in `src/vendor/rtk.ts` and the history adapter in
   `src/slim.ts`. Parse safe command wrappers, correlate shell and exec outputs,
   preserve output envelopes and completion status, and never execute history.
   Test compound-command rejection, malformed outputs, streaming sessions,
   wrapper ambiguity, successful compaction, and idempotence.
5. Update attribution, coverage inventory, README and package file/test lists.
   Run focused tests, the read-only suite, typecheck and build; review the final
   change against the inventory and history safety requirements.

## Shared interfaces

Filter functions return the original input when unsupported. The shared facade
enforces byte savings and terminal-control protection; the history adapter adds
the compaction marker and checks total byte savings. Structured formats must
validate their schema before summarizing. Default command forms that differ from
upstream's forced JSON/porcelain formats need explicit parsing or passthrough.

## Review focus

Do not summarize ambiguous shell pipelines or mixed outputs as a single command.
Do not infer a successful exit from a summary alone. Preserve unknown JSON fields
and raw record formatting outside changed output spans. Keep failures and unknown
formats intact at the history boundary. Avoid regex denial of service and retain
UTF-8 correctness. Check that packaged assets work from the installed dist tree.
